┌─────────────────────────────────────────┐
│         业务（Business）                │ ← 做什么（What）
│  - 定义目标和流程                        │
│  - 包含多个功能                          │
└─────────────────────────────────────────┘
                    ↓ 包含/调用
┌─────────────────────────────────────────┐
│         功能（Function）                │ ← 怎么做（How）
│  - 提供具体能力                          │
│  - 可被多个业务复用                      │
└─────────────────────────────────────────┘
                    ↓ 实现
┌─────────────────────────────────────────┐
│         代码（Code）                    │ ← 具体实现（Implementation）
│  - 实现功能的具体代码                    │
│  - 包含类、方法等                        │
└─────────────────────────────────────────┘

| 关系 | 说明 |
|------|------|
| 业务 → 功能 | 一个业务包含/调用多个功能 |
| 功能 → 业务 | 一个功能可以被多个业务复用 |
| 业务层 | 关注"做什么"（What） |
| 功能层 | 关注"怎么做"（How） |
